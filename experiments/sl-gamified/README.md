# Analysis scripts
- Main analysis script: **wd_manuscript_clean_script.R**
- Group-level analysis script: **wd_manuscript_group_analysis_clean.Rmd**

# Data files
Raw data (input for main analysis script):
-   **wd_cohort1_assessments.csv** / **wd_cohort2_assessments.csv**: all standardized assessment scores
-   **wd_cohort1_demographics.csv** / **wd_cohort2_demographics.csv**: all collected demographic information
-   **wd_cohort1_ssl_s2_transcript.csv / wd_cohort2_ssl_s1_transcript.csv / wd_cohort2_ssl_s2_transcript.csv**: raw transcriptions for the SSL task
 
  
Group-level data (input for Group-level analysis script):
-   **cohort1_afc_by_trial.csv**: by-trial 2AFC accuracy for all Experiment 1 participants
-   **cohort1_sicr_mean.csv**: mean accuracy for the SICR task for all Experiment 1 participants
-   **cohort1_ssl_sicr_by_trial_s2.csv**: by-trial SICR scores for all Experiment 1 participants at timepoint 2
-   **cohort2_afc_by_trial.csv:**: by-trial 2AFC accuracy for all Experiment 1 participants
-   **cohort2_sicr_mean.csv**: mean accuracy for the SICR task for all Experiment 2 participants
-   **cohort2_ssl_sicr_by_trial_s1.csv**: by-trial SICR scores for all Experiment 2 participants at timepoint 1
-   **cohort2_ssl_sicr_by_trial_s2.csv**: by-trial SICR scores for all Experiment 2 participants at timepoint 1
